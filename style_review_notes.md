# Style Review Notes - Apply in ONE pass

## Key Changes to Make
1. More kinetic/asymmetric layouts - staggered grids, controlled overlaps, off-axis glows
2. Stronger display typography - more compressed, heavier, more dominant headlines
3. Stronger brand mark - pixel-glide motif recurring in badges, dividers, CTA moments
4. Reduce generic rounded-card rhythm - vary card styles (dashboard, neon frames, thumbnail strips)
5. Cyan = primary brand signal (CTAs, numbers, active states); Pink = secondary contrast only
