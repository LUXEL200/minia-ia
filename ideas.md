# Minia IA — Design System

## Chosen Approach: Neon Noir

## Style Decisions

- **Layout rule:** Sections avoid default centered stacking; every major page includes asymmetric grids, controlled overlaps, cropped media, or offset glow fields to create kinetic motion even in a static frame.
- **Brand motif rule:** The Minia IA "M" uses a cyan-to-pink pixel-glide treatment, and the same pixel/glide motif must recur subtly in badges, dividers, image frames, or CTA moments.
- **Accent rule:** Cyan `#06B6D4` is the primary brand signal reserved for main CTAs, key performance numbers, active states, and highest-priority emphasis; pink `#EC4899` is secondary contrast, not equal decoration everywhere.
- **Typography:** Space Grotesk for display/headlines (bold, compressed, dominant), Inter for body text, JetBrains Mono for labels/badges. Headlines feel brutal and fast.
- **Cards:** Varied styles — some as dashboard panels, some as neon frames, some as compressed control panels — not interchangeable rounded tiles.
- **Section labels:** Each section uses a `/ Label` monospace prefix in cyan or pink as a consistent branding element.
