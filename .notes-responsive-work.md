## PageHeader component created at:
`client/src/components/PageHeader.tsx`
- Props: title, subtitle, backTo (default "/dashboard"), breadcrumb (array of {label, href?}), right (React.ReactNode)
- Renders breadcrumb (Home + items), title + subtitle, back button

## Pattern for adding PageHeader to each page:
1. Add `import PageHeader from "@/components/PageHeader";`
2. Replace `px-4 py-6` with `px-3 sm:px-4 py-4 sm:py-6` on the container div
3. Remove the manual "Back" Link and the manual `<h1>` + subtitle div
4. Add `<PageHeader title="..." subtitle="..." breadcrumb={[{ label: "..." }]} right={...optional...} />`
